GALVANI

Kiro brings dead Fortran back to life, and every port stands trial. It can't cheat without getting caught.

GALVANI has Kiro translate routines from SLATEC FNLIB, a 1980s library of special functions, into Python. Each port is then tested on thousands of inputs against the compiled Fortran original and against a 50-digit referee (mpmath). Where the original itself is wrong, an automated loop sends Kiro the evidence and asks it to do better.

Flaw ledger

Each row is an original that fails one range of inputs, and a Kiro port that passes the same range on 10,000 held-out inputs it never saw.

How a port earns its verdict

1. PortKiro translates the Fortran literally. It can read the source and write only routines/. It has no shell and cannot see the tests.
2. TrialThe port, the compiled original and the 50-digit referee run on the same seeded inputs, split into ranges. Errors are measured in ULPs (units in the last place).
3. EvidenceFor failures, the loop sends a report, a precision autopsy (the same code run in double and in 60 digits) and a check of every copied constant. Each change is also split into separate edits and each one is tried on its own.
4. VerdictAny round that makes things worse, or doesn't help, is undone with a new commit. HEALED means the port beats the original on its failing range, keeps the rest, and the held-out run agrees.

Verdicts: RESURRECTED (passes everywhere), UNDEAD (close), STILL DEAD (fails), HEALED (fixes a flaw of the original). Every Kiro edit is committed exactly as written, failed attempts included.

Re-run it yourself

Pick a routine and an input. Your browser loads Python (Pyodide, about 10 MB, once) and runs three things on that input: Kiro's faithful port (which matched the compiled original in its trial), Kiro's healed port, and the 50-digit referee. Nothing is sent anywhere.

If Python can't load (offline, or a blocked CDN), the precomputed tables above show the same three columns for fixed inputs, computed when this page was built.

Census of the originals

Built from commit of the public repository. Every trial number comes from a committed run file, linked next to it; spot checks are computed from committed code when the page is built.

GALVANI checks numbers against a referee. It doesn't claim any other library is built on SLATEC, and a HEALED port is only as good as the inputs it was tested on.
